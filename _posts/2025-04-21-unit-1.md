## Core Concepts

### Primitive Data Types
- Java has **8 primitive types**, but **only 4 are tested** on the AP exam:
  - `int` – integers (whole numbers): `-2`, `0`, `57`
  - `double` – floating point numbers (decimals): `3.14`, `0.0`, `-27.55`
  - `boolean` – true or false values: `true`, `false`
  - `char` – single characters: `'a'`, `'%'`, `'9'` (in **single quotes**)
- The other 4 types (`long`, `short`, `byte`, `float`) may come up but aren't as commonly tested.

### Type Conversion (Casting)
- **Implicit Casting (Widening)**: Automatically happens when you assign a smaller type to a larger one.
  - Example: `int a = 5; double b = a; // a is cast to double automatically`
  - **No data loss** when widening.
  
- **Explicit Casting (Narrowing)**: You need to manually cast when going from a larger type to a smaller one.
  - Example: `double a = 5.7; int b = (int) a; // b becomes 5`
  - **Warning**: This may cause **data loss** (truncating the decimal).

### Range and Memory Allocation
- **`int`**: 32-bit, ranges from `-2^31` to `2^31 - 1` (approximately `-2 billion` to `2 billion`)
- **`double`**: 64-bit, with a precision of around 15-16 digits after the decimal point.
- **`boolean`**: Only `true` or `false`, uses 1 bit of memory.
- **`char`**: 16-bit Unicode character, ranges from `'\u0000'` to `'\uffff'`.

## Key Points to Remember
- **Primitive types are immutable**: You can't change their values once assigned.
- **Primitive types are always passed by value**, which means changes in methods don’t affect the original variable.

## Code Examples

```java
// Example of Primitive Types in Java

public class PrimitiveExample {
    public static void main(String[] args) {
        int x = 10;
        double y = 3.14;
        boolean isValid = true;
        char grade = 'A';

        // Implicit casting (widening)
        double z = x; // int to double

        // Explicit casting (narrowing)
        int a = (int) y; // double to int, truncates decimal part

        System.out.println("x = " + x);
        System.out.println("y = " + y);
        System.out.println("isValid = " + isValid);
        System.out.println("grade = " + grade);
        System.out.println("z (widened) = " + z);
        System.out.println("a (narrowed) = " + a);
    }
}
```

### Output of Example
```
x = 10
y = 3.14
isValid = true
grade = A
z (widened) = 10.0
a (narrowed) = 3
```

## Common Mistakes to Avoid

1. **Confusing `int` and `double` in operations**:
   - If you divide two integers, the result is **truncated**. 
   - Example:
     ```java
     int x = 7;
     int y = 2;
     int result = x / y; // result is 3, not 3.5
     ```
   - To get a decimal result, at least one number must be a `double`:
     ```java
     double result = x / 2.0; // result is 3.5
     ```

2. **Forgetting to cast when necessary**:
   - Example:
     ```java
     double d = 9.8;
     int i = d;  // This will cause a compile-time error
     ```
   - Fix:
     ```java
     int i = (int) d; // Cast explicitly
     ```

## Example Questions

1. **Which of the following statements are valid in Java?**
   - A. `int x = 3.14;`
   - B. `double y = 5;`
   - C. `char z = "hello";`
   - D. `boolean valid = 1;`

   **Correct Answer**: B. `double y = 5;`  
   **Explanation**: 
   - A is invalid because `3.14` is a double, not an integer.
   - C is invalid because `char` can only hold a single character, not a string.
   - D is invalid because `boolean` values are either `true` or `false`, not integers.

2. **What will be the output of the following code?**

   ```java
   int a = 5;
   double b = 3.2;
   double result = a + b;
   System.out.println(result);
   ```

   **Answer**: `8.2`  
   **Explanation**: The `int` value of `a` is implicitly cast to `double` during the addition, and the result is `double` with no data loss.

## Tips for Success
- **Understand data types thoroughly**: The more comfortable you are with the types and their behaviors, the easier it will be to manipulate them in complex operations.
- **Practice with casting**: This is a key concept that trips up many students. Understand both implicit and explicit casting well.
- **Keep track of type limits**: Always remember the size of each type and the range of values it can hold, especially for `int` and `double`.
