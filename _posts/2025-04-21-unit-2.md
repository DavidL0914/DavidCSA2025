## Core Concepts

### What is an Object?
- An **object** is an instance of a **class**.
- A **class** is like a blueprint for creating objects.
- **Objects** have:
  - **Attributes** (also called **fields** or **properties**) that define their state.
  - **Methods** that define the actions they can perform.

### Creating and Using Objects
- Objects are created using the **new** keyword followed by the class constructor.
  - Example:
    ```java
    String name = new String("Alice");
    ```

### Declaring and Instantiating Objects
- You can declare an object by specifying its type (class name) and its name:
  ```java
  Dog myDog; // Declare a Dog object
  ```
- To **instantiate** the object (create it in memory), you use the `new` keyword:
  ```java
  myDog = new Dog(); // Instantiate the Dog object
  ```

### Using Methods of an Object
- Methods of an object are invoked using the dot notation:
  ```java
  myDog.bark(); // Call the bark method of the Dog object
  ```

### Example of a Simple Class
- A simple **Dog** class might look like this:
  ```java
  public class Dog {
      // Attributes
      String breed;
      int age;
      
      // Constructor
      public Dog(String breed, int age) {
          this.breed = breed;
          this.age = age;
      }
      
      // Method
      public void bark() {
          System.out.println("Woof! Woof!");
      }
  }
  ```

### Creating and Using the Object
- To create an object of type **Dog** and use its method:
  ```java
  public class Main {
      public static void main(String[] args) {
          Dog myDog = new Dog("Golden Retriever", 3);
          System.out.println("Breed: " + myDog.breed);
          System.out.println("Age: " + myDog.age);
          myDog.bark();
      }
  }
  ```

### Output of Example
```
Breed: Golden Retriever
Age: 3
Woof! Woof!
```

## Common Mistakes to Avoid

1. **Forgetting to instantiate objects**: Declaring an object without using `new` will result in a **null reference**.
   - Example:
     ```java
     Dog myDog;
     myDog.bark(); // Error: myDog is not instantiated
     ```

2. **Incorrect method call**: Make sure that you're using the correct object and its corresponding method.
   - Example:
     ```java
     Dog myDog = new Dog("Golden Retriever", 3);
     myDog.run(); // Error: run() method does not exist in the Dog class
     ```

## Example Questions

1. **Which of the following statements are true about the Dog class?**
   - A. The `Dog` class has a method called `bark`.
   - B. The `Dog` class has no constructors.
   - C. The `Dog` class has a field `age` of type `int`.
   - D. The `Dog` class has no attributes.

   **Correct Answer**: A, C  
   **Explanation**:
   - A is true because the `bark()` method is defined.
   - C is true because there is an `age` attribute of type `int`.
   - B is false because the `Dog` class has a constructor.
   - D is false because the `Dog` class has attributes like `breed` and `age`.

2. **What will be the output of the following code?**

   ```java
   Dog myDog = new Dog("Bulldog", 5);
   System.out.println(myDog.breed);
   ```

   **Answer**: `Bulldog`  
   **Explanation**: The value of the `breed` attribute is printed, which is `Bulldog`.

## Tips for Success
- **Understand the relationship between classes and objects**: Know that classes are the blueprints, and objects are instances of those blueprints.
- **Practice creating and using objects**: Write code that creates objects of various classes and calls methods to get comfortable with the syntax.
- **Remember object state vs. behavior**: The **state** is what the object **has** (its attributes), and the **behavior** is what the object **does** (its methods).
- **Master constructor usage**: Constructors are essential for setting up objects properly. Practice with default and parameterized constructors.
