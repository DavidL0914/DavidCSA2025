## Core Concepts

### What is a Boolean Expression?
- A **boolean expression** is an expression that evaluates to either `true` or `false`.
- Examples of boolean expressions:
  - `5 > 3` (evaluates to `true`)
  - `10 == 15` (evaluates to `false`)
  - `x != y` (evaluates to `true` or `false` depending on the values of `x` and `y`)

### Boolean Operators
- **Logical Operators** are used to combine or modify boolean expressions:
  - `&&` (AND): Returns `true` if both operands are `true`.
    - Example: `(5 > 3) && (10 > 5)` → `true`
  - `||` (OR): Returns `true` if at least one operand is `true`.
    - Example: `(5 > 3) || (10 < 5)` → `true`
  - `!` (NOT): Reverses the boolean value.
    - Example: `!(5 > 3)` → `false`

### If Statements
- The `if` statement is used to make decisions in your code.
- **Syntax**:
  ```java
  if (booleanExpression) {
      // code to execute if the expression is true
  }
  ```
- **Example**:
  ```java
  if (x > 10) {
      System.out.println("x is greater than 10");
  }
  ```

### Else and Else-If Statements
- Use `else` to specify an alternative block of code when the `if` condition is `false`.
- Use `else if` to test multiple conditions sequentially.
  ```java
  if (x > 10) {
      System.out.println("x is greater than 10");
  } else if (x == 10) {
      System.out.println("x is equal to 10");
  } else {
      System.out.println("x is less than 10");
  }
  ```

### Example of an If Statement with Boolean Expression
```java
public class Main {
    public static void main(String[] args) {
        int age = 20;
        
        if (age >= 18) {
            System.out.println("You are an adult.");
        } else {
            System.out.println("You are a minor.");
        }
    }
}
```

### Output of Example
```
You are an adult.
```

## Common Mistakes to Avoid

1. **Using Assignment `=` instead of Comparison `==`**:
   - A common mistake is using `=` (assignment operator) when you mean to use `==` (equality operator).
     - Example:
       ```java
       if (x = 5) {  // Error! This assigns 5 to x, not compares it.
           System.out.println("x is 5");
       }
       ```
     - Correct usage:
       ```java
       if (x == 5) {  // Correct: compares x to 5
           System.out.println("x is 5");
       }
       ```

2. **Forgetting to Include Braces `{}`**:
   - In Java, braces `{}` are required if you have more than one statement in an `if`, `else if`, or `else` block.
     - Example:
       ```java
       if (x > 10) 
           System.out.println("x is greater than 10");  // Single statement - works fine
           System.out.println("This will always execute!");  // This will always run
       ```
     - Correct usage:
       ```java
       if (x > 10) {
           System.out.println("x is greater than 10");
       }
       System.out.println("This will always execute!");
       ```

3. **Confusing `&&` and `||`**:
   - Remember that `&&` requires both conditions to be `true` while `||` requires only one condition to be `true`.
   - Example:
     ```java
     if (x > 5 && x < 10) {  // Correct usage for AND
         System.out.println("x is between 5 and 10");
     }
     ```

## Example Questions

1. **Which of the following is the correct use of a boolean expression?**
   - A. `if (x = 5) {}`  
   - B. `if (x == 5) {}`  
   - C. `if x == 5 {}`  
   - D. `if (x > 10) {}`  

   **Correct Answer**: B, D  
   **Explanation**:  
   - B is correct because `==` is used to compare `x` to 5.  
   - D is correct because `x > 10` is a valid boolean expression.  
   - A is incorrect because `=` is an assignment operator, not a comparison operator.  
   - C is incorrect because the syntax `if x == 5` is missing parentheses around the condition.

2. **What will be the output of the following code?**

   ```java
   int x = 7;
   if (x > 10) {
       System.out.println("x is greater than 10");
   } else if (x == 7) {
       System.out.println("x is equal to 7");
   } else {
       System.out.println("x is less than 7");
   }
   ```

   **Answer**: `x is equal to 7`  
   **Explanation**: Since `x` is 7, the second condition (`x == 7`) is true, so the corresponding block will execute.

3. **What will be the output of the following code?**

   ```java
   int x = 15;
   if (x > 5 && x < 20) {
       System.out.println("x is between 5 and 20");
   } else {
       System.out.println("x is outside the range");
   }
   ```

   **Answer**: `x is between 5 and 20`  
   **Explanation**: The condition `(x > 5 && x < 20)` is true because `x` is 15, so the first block is executed.

## Tips for Success
- **Practice with different combinations of `if`, `else if`, and `else` statements**: This helps you get comfortable with flow control in Java.
- **Test multiple conditions using logical operators**: Understanding how `&&` and `||` work is key to writing correct boolean expressions.
- **Check your equality operators**: Always double-check that you're using `==` for comparison, not `=`.
- **Use braces `{}` for clarity**: Even if there's only one statement in a block, it's good practice to use braces for better readability and to avoid mistakes.
