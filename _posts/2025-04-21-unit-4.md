## Core Concepts

### What is Iteration?
- **Iteration** is the process of repeatedly executing a set of statements.
- There are three primary types of loops in Java:
  - **For Loop**
  - **While Loop**
  - **Do-While Loop**

### For Loop
- The **for loop** is typically used when you know in advance how many times you want to execute a statement or a block of statements.
- **Syntax**:
  ```java
  for (initialization; condition; increment/decrement) {
      // code to execute
  }
  ```
- **Example**:
  ```java
  for (int i = 0; i < 5; i++) {
      System.out.println(i);
  }
  ```
  - **Explanation**: This loop initializes `i` to 0, checks if `i` is less than 5, and increments `i` by 1 on each iteration.

### While Loop
- The **while loop** is used when you want to repeat a block of code an indefinite number of times, as long as the condition is `true`.
- **Syntax**:
  ```java
  while (condition) {
      // code to execute
  }
  ```
- **Example**:
  ```java
  int i = 0;
  while (i < 5) {
      System.out.println(i);
      i++;
  }
  ```
  - **Explanation**: This loop executes as long as `i` is less than 5, printing the value of `i` each time and incrementing it.

### Do-While Loop
- The **do-while loop** is similar to the `while` loop, except that the condition is checked **after** the code block has executed, ensuring that the loop runs at least once.
- **Syntax**:
  ```java
  do {
      // code to execute
  } while (condition);
  ```
- **Example**:
  ```java
  int i = 0;
  do {
      System.out.println(i);
      i++;
  } while (i < 5);
  ```
  - **Explanation**: This loop executes the block of code once, and then checks if `i` is less than 5. If the condition is still true, it will continue looping.

### Example of Loops in Action
```java
public class Main {
    public static void main(String[] args) {
        // For loop
        for (int i = 0; i < 5; i++) {
            System.out.println("For Loop: " + i);
        }

        // While loop
        int j = 0;
        while (j < 5) {
            System.out.println("While Loop: " + j);
            j++;
        }

        // Do-while loop
        int k = 0;
        do {
            System.out.println("Do-While Loop: " + k);
            k++;
        } while (k < 5);
    }
}
```

## Common Mistakes to Avoid

1. **Infinite Loops**:
   - A common error occurs when the loop condition is never met, causing the loop to run forever.
     - Example of an infinite loop:
       ```java
       int i = 0;
       while (i < 5) {
           // missing i++ here
           System.out.println(i);
       }
       ```
   - **Solution**: Ensure the loop variable is updated within the loop to eventually break the condition.
     - Corrected code:
       ```java
       int i = 0;
       while (i < 5) {
           System.out.println(i);
           i++;  // Correct update of the loop variable
       }
       ```

2. **Off-by-One Errors**:
   - Off-by-one errors occur when the loop executes one more or one fewer time than expected. This typically happens with incorrect boundary conditions.
     - Example:
       ```java
       for (int i = 0; i <= 5; i++) {  // Will execute 6 times
           System.out.println(i);
       }
       ```
   - **Solution**: Check the loop boundaries and ensure you are iterating the correct number of times.

3. **Using a `for` loop when you don’t know the number of iterations**:
   - A `for` loop is often used when the number of iterations is known in advance, but if you need an unknown number of iterations, a `while` or `do-while` loop is more appropriate.
     - Example:
       ```java
       // Wrong: Using for loop without knowing number of iterations
       for (; someCondition;) {
           // some code
       }
       ```
     - **Solution**: Use a `while` loop for situations where the number of iterations is not known.
       ```java
       while (someCondition) {
           // some code
       }
       ```

## Example Questions

1. **Which of the following is the correct syntax for a `for` loop in Java?**
   - A. `for (int i = 0; i < 10; i++) {}`  
   - B. `for int i = 0; i < 10; i++ {}`  
   - C. `for (int i = 0; i < 10) {}`  
   - D. `for (int i = 0; i < 10; i++)`  

   **Correct Answer**: A  
   **Explanation**:  
   - Option A has the correct syntax: `for (initialization; condition; increment)`.  
   - Option B is incorrect because it lacks parentheses.  
   - Option C is incorrect because it is missing a closing parenthesis at the end of the loop.  
   - Option D is incorrect because the loop is missing braces `{}` around the block of code to execute.

2. **What will be the output of the following code?**
   ```java
   int i = 0;
   while (i < 3) {
       System.out.println(i);
       i++;
   }
   ```
   **Answer**: 
   ```
   0
   1
   2
   ```

3. **What is wrong with the following loop?**
   ```java
   for (int i = 0; i < 10; i++) {
       System.out.println(i);
   }
   ```
   **Answer**: Nothing is wrong with this loop. It correctly prints the numbers from 0 to 9.
   - **Explanation**: The loop starts with `i = 0`, checks if `i` is less than 10, and then increments `i` after each iteration.

4. **What is the output of the following `do-while` loop?**
   ```java
   int i = 5;
   do {
       System.out.println(i);
       i--;
   } while (i > 0);
   ```
   **Answer**:
   ```
   5
   4
   3
   2
   1
   ```

## Tips for Success
- **Understand the difference between the types of loops**: `for` is great when you know how many iterations you want, `while` is for unknown iterations (but checks the condition first), and `do-while` ensures the block is executed at least once.
- **Avoid infinite loops**: Always make sure that the condition in your loop will eventually become `false` to avoid infinite loops.
- **Use `break` and `continue` statements**: `break` can exit a loop early, and `continue` can skip the current iteration and go to the next one.
- **Check your loop bounds**: Be cautious of off-by-one errors that can cause your loop to run more or fewer times than expected.
