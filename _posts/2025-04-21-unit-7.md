## Core Concepts

### What is an ArrayList?
- An `ArrayList` is part of the **Java Collections Framework** and allows you to create resizable arrays.
- Unlike arrays, the size of an `ArrayList` can **dynamically change**.
- Only **objects** can be stored in an `ArrayList` (no primitive types like `int`, `double`, etc.).
- For primitive types, use wrapper classes: `Integer`, `Double`, `Boolean`, etc.

### Importing and Declaring an ArrayList
- You must import the `ArrayList` class:
  ```java
  import java.util.ArrayList;
  ```

- Declaration:
  ```java
  ArrayList<Type> listName = new ArrayList<Type>();
  ```

- Example:
  ```java
  ArrayList<String> names = new ArrayList<String>();
  ```

- Java 7+ allows type inference:
  ```java
  ArrayList<String> names = new ArrayList<>();
  ```

### Common Methods

| Method | Description |
|--------|-------------|
| `add(element)` | Adds element to end of list |
| `add(index, element)` | Inserts element at specified index |
| `get(index)` | Returns the element at index |
| `set(index, element)` | Replaces element at index |
| `remove(index)` | Removes element at index |
| `size()` | Returns number of elements |
| `clear()` | Removes all elements |
| `indexOf(element)` | Returns first index of element (-1 if not found) |
| `contains(element)` | Returns true if element exists in list |

### Example: Using ArrayList in Java
```java
import java.util.ArrayList;

public class ArrayListExample {
    public static void main(String[] args) {
        ArrayList<String> fruits = new ArrayList<>();
        
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Cherry");
        
        System.out.println("First fruit: " + fruits.get(0));  // Apple
        System.out.println("Total fruits: " + fruits.size()); // 3

        fruits.set(1, "Blueberry"); // Replaces Banana
        fruits.remove(2);           // Removes Cherry

        for (String fruit : fruits) {
            System.out.println(fruit);
        }
    }
}
```

### Output of Example
```
First fruit: Apple
Total fruits: 3
Apple
Blueberry
```

## Common Mistakes to Avoid

1. **Using primitives instead of wrapper classes**
   - `ArrayList<int>` is invalid. Use `ArrayList<Integer>` instead.

2. **ArrayList IndexOutOfBoundsException**
   - Trying to `get`, `set`, or `remove` an index that does not exist.
   - Always ensure `0 <= index < list.size()`.

3. **Misunderstanding how `remove()` works**
   - `list.remove(index)` removes by index.
   - `list.remove(Object)` removes by value, but only removes the first occurrence.

4. **Mixing `add(index, value)` vs `add(value)`**
   - `add(value)` appends to the end.
   - `add(index, value)` inserts at that position and shifts everything after it.

5. **Thinking `size()` gives last index**
   - `size()` returns the number of elements, but the last index is `size() - 1`.

## Example Questions

### Question 1: What is the output?
```java
ArrayList<Integer> nums = new ArrayList<>();
nums.add(5);
nums.add(3);
nums.add(8);
nums.set(1, 9);
System.out.println(nums);
```

**Answer:**
```
[5, 9, 8]
```

### Question 2: Which method removes all elements from an ArrayList?
- A. `clear()`
- B. `deleteAll()`
- C. `removeAll()`
- D. `erase()`

**Correct Answer:** A

### Question 3: What does `list.get(list.size() - 1)` return?
- A. The total number of elements
- B. The last element
- C. An error
- D. The first element

**Correct Answer:** B

### Question 4: What is the result of this code?
```java
ArrayList<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list.add(1, "C");
System.out.println(list);
```

**Answer:**
```
[A, C, B]
```

## Tips for Success

- Use a **for-each loop** to traverse the list when you don’t need index access:
  ```java
  for (String item : list) {
      System.out.println(item);
  }
  ```

- Use a **traditional for loop** when you need to access by index or modify elements:
  ```java
  for (int i = 0; i < list.size(); i++) {
      list.set(i, list.get(i).toUpperCase());
  }
  ```

- Be cautious when **removing elements while looping** — this can lead to errors or skipped elements. Use reverse loops or iterators when needed.

- Always check the **size** of the list before accessing an index to avoid exceptions.

- Remember that **ArrayLists store objects**, not primitives.
