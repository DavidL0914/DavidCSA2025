## Core Concepts

### What is a 2D Array?
- A **2D array** is an array of arrays – think of it as a table or grid with **rows and columns**.
- Syntax: `type[][] arrayName = new type[rows][columns];`
- Access individual elements using two indices:
  ```java
  array[row][column]
  ```

### Declaration and Initialization

```java
int[][] matrix = new int[3][4]; // 3 rows, 4 columns
```

- Initialized with default values (`0` for ints, `null` for objects).
- You can also initialize manually:

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
```

- This creates a 2x3 matrix.

### Accessing and Modifying Values

```java
matrix[0][1] = 99; // Sets row 0, column 1 to 99
int val = matrix[1][2]; // Accesses value at row 1, column 2
```

### Traversing 2D Arrays

#### Using Nested Loops:

```java
for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[0].length; col++) {
        System.out.print(matrix[row][col] + " ");
    }
    System.out.println();
}
```

### Row-Major vs Column-Major

- Java uses **row-major** order: outer loop is rows, inner is columns.
- `matrix.length` → number of rows
- `matrix[0].length` → number of columns (assumes non-jagged)

### Jagged Arrays
- Arrays where rows may have different lengths:
```java
int[][] jagged = {
    {1, 2},
    {3, 4, 5}
};
```
- `jagged[1].length` is 3, `jagged[0].length` is 2

## Example: Printing All Values
```java
int[][] table = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int row = 0; row < table.length; row++) {
    for (int col = 0; col < table[0].length; col++) {
        System.out.print(table[row][col] + " ");
    }
    System.out.println();
}
```

### Output:
```
1 2 3 
4 5 6
```

## Common Mistakes to Avoid

1. **Assuming square arrays**  
   - Don’t assume all rows are the same length unless initialized that way.

2. **Swapping row/column indices**
   - `array[row][col]`, not `array[col][row]`

3. **Incorrect loop conditions**
   - Always use `.length` and `.length` again for nested loop (outer: rows, inner: columns)

4. **Accessing indices out of bounds**
   - Leads to `ArrayIndexOutOfBoundsException`

### Question 3: Which loop correctly prints all elements?
- A.  
```java
for (int i = 0; i < arr[0].length; i++) {
    for (int j = 0; j < arr.length; j++) {
        System.out.println(arr[i][j]);
    }
}
```

- B.  
```java
for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[0].length; j++) {
        System.out.println(arr[i][j]);
    }
}
```

**Correct Answer:** B

## Tips for Success

- Use nested loops with correct bounds:
  ```java
  for (int i = 0; i < array.length; i++) {
      for (int j = 0; j < array[i].length; j++) {
          // Access array[i][j]
      }
  }
  ```

- For jagged arrays, always check each row's length individually.
- Practice writing helper methods that take in 2D arrays and return values like:
  - Sum of all elements
  - Max element
  - Whether a specific value exists

- Master how to **iterate** by row, by column, and diagonally.
