## Core Concepts

### What is Inheritance?
- **Inheritance** allows a class to inherit fields and methods from another class.
- Promotes **code reuse** and supports **polymorphism**.
- A class that inherits is a **subclass**; the class it inherits from is the **superclass**.

```java
public class Animal {
    public void speak() {
        System.out.println("Animal sound");
    }
}

public class Dog extends Animal {
    public void speak() {
        System.out.println("Bark");
    }
}
```

### Key Terms
- **Superclass**: The class being inherited from.
- **Subclass**: The class that inherits.
- **extends** keyword: Used to denote inheritance.
- **Override**: Replacing a superclass method in a subclass.
- **super**: Refers to the superclass version of a method or constructor.

---

## Overriding Methods

- Same method name and signature as the superclass.
- Subclass version is used at runtime (polymorphism).
- Use `@Override` annotation to indicate intent.

```java
public class Dog extends Animal {
    @Override
    public void speak() {
        System.out.println("Bark");
    }
}
```

---

## The `super` Keyword

- Access superclass methods or constructors.

```java
public class Dog extends Animal {
    public void speak() {
        super.speak(); // Calls Animal's speak
        System.out.println("Bark");
    }
}
```

---

## Constructors and Inheritance

- Subclass constructors automatically call `super()` if not specified.
- Can explicitly call a superclass constructor with parameters:

```java
public class Animal {
    public Animal(String name) {
        System.out.println("Animal: " + name);
    }
}

public class Dog extends Animal {
    public Dog() {
        super("Doggo");
    }
}
```

---

## Polymorphism

- A **superclass reference** can refer to a **subclass object**.
- Actual method called is determined at runtime.

```java
Animal a = new Dog();  // Polymorphism
a.speak(); // Calls Dog’s version if overridden
```

---

## Object Class

- Every class in Java **implicitly extends** `Object`.
- `Object` methods include `toString()`, `equals()`, `hashCode()`.
- Can override `toString()` to provide meaningful object descriptions.

---

## Example: Polymorphism and Overriding

```java
class Animal {
    public void speak() {
        System.out.println("Animal sound");
    }
}

class Cat extends Animal {
    @Override
    public void speak() {
        System.out.println("Meow");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Cat();
        a.speak();
    }
}
```

### Output:
```
Meow
```

---

## Common Mistakes to Avoid

- **Forgetting to use `@Override`** – Helps catch typos or signature mismatches.
- **Not calling `super()`** when needed in constructors.
- **Using private fields in subclasses** – private fields are not inherited; use `protected` or provide accessors.
- **Overloading vs Overriding confusion** – Overriding = same signature in subclass. Overloading = same method name, different parameters in same class.

## Tips for Success

- Use `@Override` to clarify your intent when overriding.
- Understand that **actual object type** determines method behavior during runtime.
- Write helper methods in the superclass so all subclasses inherit them.
- Use **polymorphism** to simplify code and reduce duplication.
