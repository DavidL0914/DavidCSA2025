- **Multicompartment imaging of the brain**  
  *Role: Intern Researcher and Developer*  
This project aimed to develop a new **MRI scanning technique** to better understand what’s going on inside the brain—specifically, the different types of tissues and fluids like **myelin**, **macromolecules**, and **water**. This is especially useful for studying brain diseases like **multiple sclerosis (MS)**, where these components are often damaged or changed.
   - **Conducted research analysis** by studying the MRI data collected from the scans and helping interpret what the results mean for healthy vs. diseased brains.
   - **Helped code and develop the program in MATLAB**, which processed the MRI images and calculated important brain measurements like the amount of myelin or free water in different brain regions.

## Intro to ML Experience

- **Mental Health App**
    In 2022, I co-developed **MindMatters**, an app submitted to the **Congressional App Challenge**, which uses **machine learning to monitor users’ sleep patterns** and promote mental wellness. The app provides **personalized feedback and recommendations** to help users build healthier habits and improve mental health.
    - Developed the app using **Flutter** for a cross-platform mobile experience.
    - Integrated **Firebase** for real-time user authentication and cloud data storage.
    - Collected sleep data through manual input and wearable integration (e.g., accelerometer/gyroscope support planned).
    - Used **Python with Scikit-learn** to build a **supervised ML model** that:
        - Identified abnormal sleep patterns over time
        - Predicted mental health risk indicators based on user trends
        - Built a dashboard for users to visualize sleep quality trends, ML analysis, and mood correlations.

This project sparked my interest in combining **ML and human-centered design** to build impactful tools to better society.
